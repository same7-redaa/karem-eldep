   الروابط المقترحة تحت `/alexandria/`:
   `family-lawyer`, `real-estate-lawyer`, `immigration-lawyer`, `civil-lawyer`, `commercial-lawyer`, `corporate-lawyer`, `lawyer-for-foreigners`, `international-lawyer`, `international-arbitration-lawyer`, `maritime-arbitration-lawyer`, `mediation-lawyer`.
   (أسرة وأحوال شخصية في صفحة واحدة لأنهما نفس المعنى.)
2. **الربط:** إضافة المسارات في `src/AppRouter.tsx` (عربي و`/en`)، وفي `scripts/prerender.mjs`، وفي `scripts/generate_sitemap.cjs`، وتحديث روابط الخدمات في `src/pages/cities/Alexandria.tsx`.
3. **المدونة:** نشر المقالات الخمسة الكاملة من `docs/blog-articles/`، إضافة `BlogPosting` و`BreadcrumbList` في `BlogPost.tsx`، وتقصير العناوين.

5. **البناء والتحقق:** `npm run build` ثم فحص الصفحات الناتجة.
6. **بعد موافقة صاحب الموقع فقط:** commit ثم push (النشر تلقائي على Vercel)، ثم إعادة إرسال الخريطة وطلب أرشفة الصفحات الجديدة والخمس غير المؤرشفة.

## 4. مطلوب من صاحب الموقع

- **Vercel:** تغيير التحويل إلى 308 Permanent Redirect ثم Save.
- **Google Maps (الفرعان):**
  - رابط الموقع: الإسكندرية ← `https://www.ke-lawyer.com/alexandria`، شرم ← `https://www.ke-lawyer.com/sharm-el-sheikh`.
  - توحيد صيغة الاسم بين الفرعين.
  - تصحيح الردود المنسوخة على المراجعات (مثال: رد "يا نهى" على مراجعة Emad Morsy في شرم) والرد بالعربية على المراجعات العربية.
  - إضافة فئات فرعية وخدمات ووصف وصور ومنشورات أسبوعية.
  - مراجعة عنوان شرم "123 البحر" إن كان غير دقيق.
- **OpenSEO:** تسجيل الدخول للإضافة داخل Claude Code لاستخدامها في حجم البحث على الكلمات.
- **مراجعة قانونية:** محتوى صفحات الإسكندرية والمقالات الكاملة قبل النشر، خصوصاً التحكيم البحري والهجرة.
